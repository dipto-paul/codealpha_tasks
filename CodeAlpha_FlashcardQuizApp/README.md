# 🧠 Flashcard Quiz App

A simple and interactive **Flashcard Quiz App** built with **Flutter & Dart** as part of my **CodeAlpha App Development Internship**.

This application helps users learn and revise different topics using question-and-answer flashcards. Users can view questions, reveal answers, navigate between cards, and add their own custom flashcards. 📚✨

---

## 🚀 Features

* 📝 View questions using flashcards
* 💡 Show answers with a single tap
* ⬅️ Navigate to the previous flashcard
* ➡️ Navigate to the next flashcard
* ➕ Add new custom flashcards
* 🧭 Bottom Navigation Bar
* 🎨 Clean and simple user interface
* 📱 Flutter-based cross-platform application

---

## 🎯 How It Works

### 1️⃣ Flashcards

The app displays a question on the flashcard.

### 2️⃣ Show Answer

Users can tap the **Show Answer** button to reveal the answer.

### 3️⃣ Navigation

Users can move between flashcards using the **Previous** and **Next** buttons.

### 4️⃣ Add Flashcard

From the **Add Card** section, users can enter a new question and answer and add it to the flashcard list.
