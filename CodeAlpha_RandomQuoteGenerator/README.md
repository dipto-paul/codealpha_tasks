# 💬 Random Quote Generator

A simple and elegant **Random Quote Generator App** built with **Flutter & Dart** as part of my **CodeAlpha App Development Internship**. 🚀

The app displays inspirational and motivational quotes along with their authors. Users can generate a new random quote with a single tap and enjoy a clean, minimal user interface. ✨

---

## 🚀 Features

* 💬 Display random quotes
* 👤 Show quote author
* 🔄 Generate a new quote with one tap
* ❤️ Favorites section
* 🧭 Bottom Navigation Bar
* 🎨 Clean and modern UI
* 📱 Responsive Flutter interface
* ⚡ Lightweight and easy to use

---

## 🛠️ Technologies Used

* 💙 **Flutter**
* 🎯 **Dart**
* 🎨 **Material Design**
* 🧩 **StatefulWidget & setState**
* 📦 Local quote data

## 🎯 How It Works

### 1️⃣ Open the App

When the app starts, a quote is displayed on the screen.

### 2️⃣ Generate New Quote

Tap the **New Quote** button to display another random quote.

### 3️⃣ Quote & Author

Each quote is displayed together with its respective author.

### 4️⃣ Favorites

Users can access the **Favorites** section from the bottom navigation bar.
